Skills · 开源能力资产

把 AI 辅助工程里反复验证的判断方法，做成可安装、有边界的 Skill

5 个 Skill · 托管于 aster-xu-lab/skills

这是什么

可安装

在支持 Skill 的 AI 编码宿主中安装使用，按宿主约定放入 skills 目录。

有边界

每个 Skill 是判断方法 + 流程；默认只读，或只在显式授权后执行。

非黑盒

不是自动执行的黑盒：先说明判断与流程，再决定是否执行。

Skill 资产

4 个 MIT · 1 个未指定许可

01 许可未指定

hexo-blog-post

把项目经验整理成 Hexo 博客文章：从草稿到按授权发布。

适用场景
有可复用的项目复盘、技术分析或踩坑记录，需要写成站点文章。
必要环境
已有 Hexo 站点与可用的构建环境。
仓库 aster-xu-lab/skills

仓库 aster-xu-lab/skills

skill-config-maintenance

仓库 aster-xu-lab/skills

5 个 Skill 中，4 个以 MIT 许可发布；hexo-blog-post 未指定开源许可，不能按 MIT 分发。

如何获取

手动安装，不依赖管理工具。

  1. 01

    获取仓库

    git clone https://github.com/aster-xu-lab/skills，或下载对应的 Skill 目录。

  2. 02

    放入宿主的 skills 目录

    Claude Code 个人级 ~/.claude/skills/<name>/，项目级 .claude/skills/<name>/；其他宿主按各自的 skills 目录约定放置。

  3. 03

    可选：批量管理

    CC Switch 仅用于批量管理，不是安装前置，也不是必需依赖。

安全提示

Skill 可携带脚本。安装前先读 SKILL.md 与 scripts/，确认它会读写什么、在什么条件下执行。

验证边界

已核对与尚未验证分开列出。

已核对

  • 公开内容适配：面向公开读者的文案与信息取舍已完成。
  • 结构与引用：页面结构、仓库地址与安装路径引用已检查。

尚未验证

  • 真实项目效果：尚未在真实项目中完整跑过。
  • 宿主自动路由与跨宿主行为。
  • 配置维护类 Skill 在真实用户目录、Windows、软链与 CC Switch 安装副本上的表现。
